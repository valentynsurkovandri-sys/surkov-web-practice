# Рукотвори — магазин виробів ручної роботи

Навчальний веб-проєкт з практики «WEB-технології та WEB-дизайн» (варіант 29).
Каталог handmade-товарів українських майстрів із **фільтром за ціною** та **списком бажань**.

**Автор:** Сурков Валентин, група ПЗ-26

## Стек

- Дизайн: Figma
- Клієнт: HTML5, CSS3, JavaScript, React + Vite, React Router
- Сервер: Node.js, Express
- Деплой: Vercel (клієнт), Render (API)

## Структура репозиторію

- `client/` — клієнтська частина
- `server/` — REST API на Node.js + Express
- `docs/` — ТЗ, UX, API, звіти
